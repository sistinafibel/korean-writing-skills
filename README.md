# korean-writing-skills

Claude Code 같은 코딩 에이전트가 한국어 문장과 커밋, PR 문서를 일관된 기준으로 쓰게 하는 스킬셋입니다. 스킬 두 개가 서로를 참조하도록 묶여 있어서, 에이전트가 답변을 쓸 때와 커밋이나 PR을 쓸 때 같은 문장 기준을 따릅니다.

| 스킬 | 다루는 것 |
|------|-----------|
| `natural-korean` | 한국어 답변, 문서, 화면 문구의 문장 지침입니다. 문장 성분과 조사를 생략하지 않게 하고, AI가 쓴 글에서 반복되는 문형('단순히 A가 아니라 B이다', '~하는 순간 ~된다', 불필요한 '우리', 거창한 수식어, 같은 내용의 반복 정리)을 피하게 합니다. |
| `git-writing-korean` | 커밋 메시지와 PR 문서의 작성 기준입니다. 커밋 타입 목록, 명사형으로 끝나는 제목(추가, 숨김), 고정된 PR 본문 절(작업 배경, 변경 사항, 배포 참고 사항, 확인 사항), 사용하지 않는 어휘와 기호(가운뎃점, 엠대시, 엔대시, 화살표)를 정합니다. 작성한 초안은 올리기 전에 natural-korean의 조항으로 검사합니다. |

## 만든 이유

저장소가 여러 개가 되면 커밋 메시지와 PR 본문이 그때그때 다르게 쓰입니다. 같은 사람이 쓴 저장소들에서도 새 기능 타입이 `feat`과 `feature`로 갈리고, 제목이 "추가", "뺌", "맞추기", "더한다"처럼 서로 다른 형태로 끝나고, PR 본문의 절 이름이 요약, 변경 내용, 검증, 테스트 계획으로 PR마다 달랐습니다. 에이전트에게 커밋과 PR을 맡기면 이 차이가 더 빨리 늘어납니다. 이 스킬셋은 문장 기준과 문서 구조를 한 곳에서 정해서, 사람이 쓰든 에이전트가 쓰든 같은 형식의 기록이 남게 합니다.

## 설치

### Claude Code 플러그인으로 설치

Claude Code에서 아래 두 명령을 차례로 입력합니다.

```
/plugin marketplace add sistinafibel/korean-writing-skills
/plugin install korean-writing@korean-writing-skills
```

설치하면 두 스킬이 `korean-writing:natural-korean`, `korean-writing:git-writing-korean`이라는 이름으로 등록됩니다.

### 스킬 폴더에 직접 복사

플러그인을 쓰지 않는다면 `plugins/korean-writing/skills/` 아래의 두 폴더를 `~/.claude/skills/`로 복사합니다. 프로젝트 하나에만 적용하려면 그 프로젝트의 `.claude/skills/`로 복사합니다.

### 항상 적용되게 하기

스킬은 에이전트가 필요하다고 판단할 때 불러옵니다. 커밋과 PR을 쓸 때마다 확실히 적용되게 하려면 `CLAUDE.md`나 `AGENTS.md`에 아래처럼 한 줄을 적어 둡니다.

```markdown
커밋 메시지, PR 제목, PR 본문은 git-writing-korean 스킬을 읽고 그 기준대로 쓴다.
```

## 저장소에 함께 맞춰 둘 것

`git-writing-korean`은 저장소의 commitlint 설정과 PR 템플릿이 스킬보다 우선한다고 정합니다. 그래서 저장소 쪽 설정이 스킬과 다르면 스킬 기준이 적용되지 않습니다. 기준을 여러 저장소에 적용할 때에는 다음 두 가지 설정도 함께 변경합니다.

- `commitlint.config.*`의 `type-enum`: `feature`, `fix`, `refactor`, `perf`, `docs`, `test`, `chore`, `ci`, `deploy`
- `.github/pull_request_template.md`: 작업 배경, 변경 사항, 배포 참고 사항, 확인 사항

PR 템플릿에 넣을 절 구성은 [git-writing-korean 스킬](plugins/korean-writing/skills/git-writing-korean/SKILL.md)에 있습니다.

## 출력 비교

`claude-sonnet-5-5`에 같은 입력을 보내고 시스템 프롬프트에 넣는 지침만 바꿔서 생성한 출력입니다. 샘플마다 조건별로 한 번씩 생성한 결과를 고치지 않고 그대로 실었고, 모든 입력의 끝에는 "결과만 출력해 주세요."를 붙였습니다. 처음과 이전 스킬은 2026-11-24에 생성했고, 지금 스킬은 첫 실행 결과를 확인한 뒤 스킬의 조항을 세 차례 수정하고 나서 같은 샘플로 2026-11-25에 다시 생성했습니다.

조건은 세 가지입니다. **처음**은 지침 없이 생성한 출력이고, **이전 스킬**은 fluent-korean을, **지금 스킬**은 이 저장소의 두 스킬을 넣고 생성한 출력입니다.

**1. 조사와 성분 생략**

> 다음 문장을 자연스럽게 다듬어 주세요: "캐시 무효화 누락. 배포 후 구버전 응답 지속. 키 버전 올려 해결."

| 조&#8288;건 | 출력 |
| --- | --- |
| 처&#8288;음 | 캐시 무효화가 누락되어 배포 후에도 구버전 응답이 계속 반환되었으며, 캐시 키 버전을 올려 문제를 해결했습니다. |
| 이&#8288;전&nbsp;스&#8288;킬 | 캐시 무효화 처리가 누락되어 배포 후에도 구버전 응답이 계속 반환되었으며, 캐시 키의 버전을 올려서 문제를 해결했습니다. |
| 지&#8288;금&nbsp;스&#8288;킬 | 캐시를 무효화하지 않아서 배포한 뒤에도 구버전 응답이 계속 반환되었고, 캐시 키의 버전을 올려서 해결했습니다. |

**2. 앞을 부정해서 뒤를 강조하는 문형**

> 다음 문장을 자연스럽게 다듬어 주세요: "이번 업데이트는 단순한 버그 수정이 아니라, 검색 경험의 본질적인 전환입니다."

| 조&#8288;건 | 출력 |
| --- | --- |
| 처&#8288;음 | 이번 업데이트는 단순한 버그 수정을 넘어, 검색 경험 자체를 근본적으로 바꾸는 전환점입니다. |
| 이&#8288;전&nbsp;스&#8288;킬 | 이번 업데이트는 단순히 버그를 수정하는 데 그치지 않고, 사용자가 검색을 경험하는 방식 자체를 근본적으로 바꾸었습니다. |
| 지&#8288;금&nbsp;스&#8288;킬 | 이번 업데이트에서는 버그를 수정하면서 검색 경험도 크게 바꾸었습니다. |

**3. 격언처럼 단정하는 문형**

> 다음 문장을 자연스럽게 다듬어 주세요: "인덱스를 빼는 순간, 조회 성능은 무너집니다."

| 조&#8288;건 | 출력 |
| --- | --- |
| 처&#8288;음 | 인덱스를 제거하는 순간 조회 성능이 급격히 떨어집니다. |
| 이&#8288;전&nbsp;스&#8288;킬 | 인덱스를 제거하면 조회 성능이 크게 저하됩니다. |
| 지&#8288;금&nbsp;스&#8288;킬 | 인덱스를 제거하면 조회 성능이 크게 떨어집니다. |

**4. 불필요한 '우리'**

> 다음 문장을 자연스럽게 다듬어 주세요: "이제 우리는 로그 보존 기간을 30일로 줄여야 합니다."

| 조&#8288;건 | 출력 |
| --- | --- |
| 처&#8288;음 | 이제 로그 보존 기간을 30일로 단축해야 합니다. |
| 이&#8288;전&nbsp;스&#8288;킬 | 이제 로그를 보존하는 기간을 30일로 줄여야 합니다. |
| 지&#8288;금&nbsp;스&#8288;킬 | 이제 로그 보존 기간을 30일로 줄여야 합니다. |

**5. 쉼표 과다**

> 다음 문장을 자연스럽게 다듬어 주세요: "테스트를 돌렸더니, 세 건이 실패했고, 원인을 찾아보니, 시간대 설정이 달랐고, 그래서 설정을 맞췄습니다."

| 조&#8288;건 | 출력 |
| --- | --- |
| 처&#8288;음 | 테스트를 돌렸더니 세 건이 실패했습니다. 원인을 찾아보니 시간대 설정이 달라서였고, 설정을 맞추었습니다. |
| 이&#8288;전&nbsp;스&#8288;킬 | 테스트를 실행한 결과 세 건이 실패했습니다. 원인을 확인해 보니 시간대 설정이 서로 달랐으며, 이에 따라 설정을 동일하게 맞추었습니다. |
| 지&#8288;금&nbsp;스&#8288;킬 | 테스트에서 세 건이 실패했는데 시간대 설정이 달라서 생긴 문제였으므로 설정을 맞췄습니다. |

**6. 짧게 끊어 쓴 문장**

> 다음 문장들을 자연스럽게 다듬어 주세요: "비밀번호가 만료됐어요. 로그인할 수 없어요. 재설정 메일을 보내 드렸어요."

| 조&#8288;건 | 출력 |
| --- | --- |
| 처&#8288;음 | 비밀번호가 만료되어 로그인하실 수 없습니다. 재설정 메일을 보내 드렸으니 확인해 주세요. |
| 이&#8288;전&nbsp;스&#8288;킬 | 비밀번호의 유효 기간이 만료되어 로그인할 수 없는 상태입니다. 비밀번호를 재설정하실 수 있도록 안내 메일을 보내 드렸습니다. |
| 지&#8288;금&nbsp;스&#8288;킬 | 비밀번호가 만료되어서 로그인할 수 없으니 재설정 메일을 보내 드렸어요. |

**7. 평가만 담은 수식어**

> 다음 문장을 자연스럽게 다듬어 주세요: "새 결제 모듈은 강력하고 효율적이며 확장 가능한 구조로 설계되었습니다. (참고: 카드사를 추가할 때 설정 파일 한 곳만 수정하면 됨)"

| 조&#8288;건 | 출력 |
| --- | --- |
| 처&#8288;음 | 새 결제 모듈은 강력하면서도 효율적이고 확장성 있게 설계되었습니다. 카드사를 추가할 때도 설정 파일 한 곳만 수정하면 됩니다. |
| 이&#8288;전&nbsp;스&#8288;킬 | 새 결제 모듈은 강력하고 효율적이며 확장하기 쉬운 구조로 설계되었습니다. 카드사를 추가할 때에는 설정 파일 한 곳만 수정하면 됩니다. |
| 지&#8288;금&nbsp;스&#8288;킬 | 새 결제 모듈에서는 카드사를 추가할 때 설정 파일 한 곳만 수정하면 되도록 설계했습니다. |

**8. 화면 문구**

> 파일 업로드에 실패했을 때 사용자에게 보여 줄 안내 문구를 한 문장으로 작성해 주세요. 상황: 파일 크기가 20MB를 넘으면 업로드할 수 없습니다.

| 조&#8288;건 | 출력 |
| --- | --- |
| 처&#8288;음 | 파일 크기가 20MB를 초과하여 업로드할 수 없으니, 20MB 이하의 파일로 다시 시도해 주세요. |
| 이&#8288;전&nbsp;스&#8288;킬 | 파일 크기가 20MB를 초과하여 업로드할 수 없으니, 20MB 이하의 파일을 선택한 후 다시 시도해 주시기 바랍니다. |
| 지&#8288;금&nbsp;스&#8288;킬 | 파일 크기가 20MB를 넘으면 업로드할 수 없으니, 20MB 이하의 파일을 선택해서 다시 시도해 주세요. |

**9. 커밋 제목**

> 다음 변경의 커밋 제목을 한 줄로 작성해 주세요: 회원 탈퇴 API가 이미 탈퇴한 회원에게 500을 응답하던 것을 404로 응답하도록 수정했습니다.

| 조&#8288;건 | 출력 |
| --- | --- |
| 처&#8288;음 | fix: 이미 탈퇴한 회원의 탈퇴 요청 시 500 대신 404 응답 |
| 이&#8288;전&nbsp;스&#8288;킬 | fix: 이미 탈퇴한 회원의 탈퇴 요청 시 500 대신 404를 응답하도록 수정 |
| 지&#8288;금&nbsp;스&#8288;킬 | fix: 이미 탈퇴한 회원이 회원 탈퇴를 요청하면 500 대신 404를 반환 |

**10. PR 본문의 변경 항목**

> 다음 변경을 PR 본문의 변경 사항 절에 넣을 항목 하나로 작성해 주세요: 주문 목록에서 기간 필터를 선택하면 페이지 번호가 그대로 남아 빈 화면이 표시되던 문제를, 필터를 바꿀 때 페이지를 1로 되돌리도록 수정했습니다.

| 조&#8288;건 | 출력 |
| --- | --- |
| 처&#8288;음 | \- 주문 목록에서 기간 필터를 선택하면 이전 페이지 번호가 유지되어 빈 화면이 표시되던 문제를 수정했습니다. 이제 필터를 변경하면 페이지가 1로 초기화됩니다. |
| 이&#8288;전&nbsp;스&#8288;킬 | \- 주문 목록에서 기간 필터를 선택하면 이전에 보던 페이지 번호가 그대로 유지되어 빈 화면이 표시되던 문제를 수정했습니다. 이제 필터를 변경할 때 페이지 번호가 1로 초기화되므로, 선택한 기간에 해당하는 첫 번째 페이지가 정상적으로 표시됩니다. |
| 지&#8288;금&nbsp;스&#8288;킬 | \- \*\*기간 필터 변경 시 첫 페이지로 이동\*\*: 주문 목록에서 기간 필터를 선택하면 페이지 번호가 그대로 남아 빈 화면이 표시되던 문제를 수정했습니다. 이제 필터를 바꾸면 페이지가 1로 되돌아갑니다. |
